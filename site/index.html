C'est quoi un workflow GitHub ? (ELI5)¶

Un workflow GitHub, c'est comme un robot assistant dans ton dépôt. Dès qu'il se passe quelque chose (un push, une Pull Request...), ce robot se réveille et exécute automatiquement une liste de tâches que tu as définies à l'avance.

Ces tâches peuvent être : lancer des tests, déployer un site, vérifier la qualité du code... tout ça sans que tu aies à faire quoi que ce soit manuellement.
